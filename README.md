# 🏢 برنامج المحاسبة العقارية

برنامج محاسبة متكامل للتطوير العقاري - يدير الوحدات، العملاء، العقود، الأقساط، القروض، والمصروفات.

## ✨ المميزات

- 🏢 إدارة الوحدات مع QR Code
- 👥 إدارة العملاء
- 💰 عقود البيع وجدولة الأقساط (تلقائي + يدوي)
- 💵 تحصيل الأقساط مع إيصالات PDF
- 🏦 إدارة القروض (أفراد + بنوك)
- 🧾 مصروفات الإنشاء
- 📊 تقارير شاملة + تدفق نقدي + ربحية الوحدة
- 📄 طباعة عقود وإيصالات PDF
- 👤 نظام صلاحيات (مدير / محاسب / مبيعات)
- 📱 يعمل على الموبايل
- 💾 نسخ احتياطي واسترجاع
